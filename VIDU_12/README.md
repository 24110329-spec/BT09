# Ví dụ 1 + Ví dụ 2 — Custom Login
Dựa trên project Ví dụ 1 và hướng dẫn Custom Login Spring Boot 4 + Spring Security 7 + MapStruct + Thymeleaf.

## Chức năng
- Login bằng username hoặc email.
- BCrypt password.
- Spring Security session + logout.
- Hiển thị fullname, username, email, role, avatar trong header.
- Giữ CRUD/search/pagination User/Product của Ví dụ 1.
